# Linux Commands Skill

When the user asks about a Linux command or how to do something in the terminal,
answer in exactly this format:

Command: <the command>
What it does: <one or two short sentences>
Example: <one real example the student can type>
Warning: <one safety tip, or "None" if the command is safe>

Rules:
- Use only real, standard Linux commands. If you do not know a command, say "I don't know this command" instead of guessing.
- Always add a warning for commands that delete or change files (rm, mv, chmod, chown) or that need sudo.
- Keep the whole answer under 80 words.
