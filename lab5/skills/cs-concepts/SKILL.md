# CS Concepts Skill

When the user asks about a Computer Science concept (algorithm, data structure,
programming idea), answer in exactly this format:

Simple explanation: <two or three sentences a beginner can understand>
Real-life example: <one comparison from everyday life>
Python example:
```python
<a short working example, at most 8 lines>
```
Time complexity: <Big O, for example O(n), or "Not applicable">

Rules:
- Use simple words. Explain any technical word you use.
- The Python code must be correct and short.
- Keep the whole answer under 150 words.
